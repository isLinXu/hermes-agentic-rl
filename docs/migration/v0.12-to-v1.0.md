# Migration Guide: v0.12 → v1.0

> **Version:** v1.0.0-rc1  
> **Date:** 2026-07-08  
> **Scope:** Core API freeze, deprecation cleanup, and configuration stability for the first stable release.

---

## 1. Summary

v1.0.0 marks the **first stable release** of `hermes-agentic-rl`. All core public APIs are now annotated with `@stable` and protected by the backward-compatibility policy: **breaking changes require a deprecation cycle of at least one minor version**.

If your v0.12 code only uses the public surface documented below, no source changes are required. This guide covers removed legacy symbols, renamed configuration keys, and the new stability contract.

---

## 3. Deprecated / Removed Symbols

The following symbols were deprecated in v0.12 and are **removed in v1.0.0**.

| Symbol | Location | Removal Action | Replacement |
|--------|----------|----------------|-------------|
| `AtroposTrainer` (deprecated alias) | `exporters/atropos_jsonl.py` | Removed | `AtroposJsonlExporter` or real trainer from `trainers/` |
| Legacy weight-only checkpoint format | `trainers/_checkpoint_ops.py` | Deprecated | `save_full_checkpoint` / `CheckpointManager` |

The following symbols carry **legacy compatibility aliases** but are scheduled for removal in v1.1:

| Symbol | Legacy Alias | Status |
|--------|-------------|--------|
| `TrainStats` | Re-exported in `trainers/__init__.py` | Back-compat; migrate to `trainers.train_stats.TrainStats` |
| `save_checkpoint` | `_checkpoint_ops.save_checkpoint` | Legacy format; migrate to `save_full_checkpoint` |

## 4. Configuration Changes

### 4.1 YAML Key Renames (None in v1.0)

No YAML keys were renamed between v0.12 and v1.0. All existing v0.12 YAML configs are **forward-compatible**.

### 4.2 New Required Fields (None)

v1.0 does not introduce new required configuration fields. All new features are opt-in via optional YAML blocks.

### 4.3 Behavioral Changes

| Behavior | v0.12 | v1.0 |
|----------|-------|------|
| `__version__` | `0.12.0` | `1.0.0-rc1` |
| API stability contract | `@experimental` only | `@stable` on all core APIs |
| Deprecation policy | Implicit | Explicit: 1 minor release cycle |
| `_compat.__stable_apis__` | Listed | Synchronized with `@stable` decorators |

## 5. Minimal Migration Example

### v0.12 Trainer Setup (still valid in v1.0)

```python
from hermes_agentic_rl.trainers.on_policy import OnPolicyTrainer
from hermes_agentic_rl.algos.ppo import PPOAlgo
from hermes_agentic_rl.backends.tiny import TinyBackend
from hermes_agentic_rl.envs.counting import LetterCountingEnv
from hermes_agentic_rl.core.reward_manager import RewardManager
from hermes_agentic_rl.rewards.length import LengthReward

# These imports are unchanged in v1.0.
policy = TinyBackend()
env = LetterCountingEnv()
reward_manager = RewardManager([LengthReward()])
algo = PPOAlgo(policy)

trainer = OnPolicyTrainer(
    policy=policy,
    env=env,
    reward_manager=reward_manager,
    algo=algo,
)
stats = trainer.train()
```

### v1.0 YAML Config (identical to v0.12)

```yaml
# v1.0 accepts the same config shape as v0.12.
model:
  name: "tiny"
  device: "cpu"

trainer:
  n_iters: 100
  group_size: 4
  lr: 1e-5
  max_new_tokens: 32
  temperature: 0.7
  distributed_strategy: "none"

algo:
  name: "ppo"
  kl_coef: 0.02
  clip_eps: 0.2

rewards:
  - name: "length"
    max_length: 128
```

## 6. Backward-Compatibility Promise

Starting with v1.0.0, the following rules apply to all `@stable` symbols:

1. **No breaking signature changes** without a deprecation warning in at least one minor release (e.g., v1.0 → v1.1 → v1.2 removal).
2. **No removal** of `@stable` symbols without a deprecation cycle.
3. **New optional fields** may be added to `@stable` dataclasses without a deprecation cycle.
4. **New methods** may be added to `@stable` abstract classes without a deprecation cycle.
5. **Experimental symbols** (marked with `@experimental`) are exempt from this policy and may change at any time.

## 7. Checklist Before Upgrading

- [ ] Verify your code only imports from the **Frozen Core APIs** listed in Section 2.
- [ ] Remove any usage of **Removed Symbols** listed in Section 3.
- [ ] Run `python -m pytest` — all tests should pass without modification.
- [ ] Run `ruff check` and `mypy` on your codebase.
- [ ] Check that `hermes_agentic_rl.__version__` reports `1.0.0-rc1` or later.
