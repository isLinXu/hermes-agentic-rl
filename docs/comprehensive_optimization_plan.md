# 综合优化方案：hermes-agentic-rl

## 概览

本项目（hermes-agentic-rl, v0.6.0.dev0）采用双路径架构训练 Agentic RL（GRPO/PPO）模型：
1. **train-rl**：本地 GRPO/PPO 训练，含会话 sidecar + 重播 + 自演化数据导出
2. **online-cycle**：部署的 Hermes，含会话 sidecar + 重播 + 自演化数据导出
