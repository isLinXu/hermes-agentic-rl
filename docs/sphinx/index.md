# hermes-agentic-rl

An agentic reinforcement-learning framework for training LLMs with GRPO, PPO,
and hybrid RL algorithms. Features include multi-turn tool use, curriculum
learning, RULER-based reward design, LoRA hot-reload, client-server rollout
architecture, and quantized inference backends.
